PG and Coliving Rent Prediction

This project predicts rent for PG and coliving spaces by analyzing 
data like sharing type, food availability, furnishing, and location. 
Developed in Jupyter Notebook and deployed using Streamlit on Render.

Live App
-> [https://pg-rent-api-1.onrender.com]

Project Overview
- PG/Coliving dataset preprocessing
- Feature engineering for occupancy, meal plans, and other variables
- Regression model training and evaluation
- Streamlit interface for user predictions

Tools & Libraries
- Python
- Pandas, NumPy
- Scikit-learn
- Streamlit
- Jupyter Notebook(anaconda)
